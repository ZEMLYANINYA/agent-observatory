# Threat Model

## Purpose

This document defines the initial threat model and trust boundaries for Agent Observatory.

The project observes desktop AI applications from the perspective of the operating system and independent network infrastructure.

The goal is not to assume malicious behavior, but to identify what telemetry can be trusted, what telemetry can be correlated, and where blind spots exist.

## Monitored Subjects

Initial monitored subjects include:

- Claude Desktop / Cowork
- ChatGPT Desktop
- Gemini running in a desktop browser

Future subjects may include:

- command-line AI agents;
- IDE assistants;
- MCP-enabled applications;
- local LLM runtimes;
- other desktop AI software.

## Trust Model

Agent Observatory does not automatically trust telemetry generated by the monitored application itself.

Vendor logs and application-provided diagnostics may be useful, but they are treated as supplementary evidence.

Preferred evidence sources are external to the monitored application.

Examples include:

- operating-system process telemetry;
- socket and connection metadata;
- Windows event sources;
- independent network observations;
- Linux network sensor telemetry.
